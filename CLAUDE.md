# Claude instructions for VietMac

Read [AGENTS.md](AGENTS.md) for the shared project instructions.
Claude and Codex use the same specifications, tasks, and development ledger.

OpenSpec commands are in `.claude/commands/opsx` and skills are in `.claude/skills`.
Use `/opsx:apply <change>` to work on an active change. `docs/project-status.md` lists the active changes and the next work.
Invoke terminal OpenSpec operations through `./scripts/openspec.sh`.

Read `CLAUDE.local.md` if it exists. Keep personal settings out of shared files.
